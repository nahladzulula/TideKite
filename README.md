# TideKite

TideKite facilitates real-time event-driven stream-processing and data-aggregation within a scalable, high-performance engine architecture.

With TideKite, you get a lightweight tool that stays out of your way.

**What you get**

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/TideKite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
